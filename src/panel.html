Binance API

Without a key the bot runs in test mode: 1,000 pretend USDT, Binance's real prices. With a testnet key (testnet.binance.vision) it trades practice money on Binance's test exchange. Untick Testnet only for a real key: then it trades real money. Saving a key switches to it; the Test mode / My Binance account switch at the top goes back and forth. A key needs only spot trading, never withdrawals.
